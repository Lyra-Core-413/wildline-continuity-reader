# RC1 export changes

Only the release copy is changed. Original packages, code, historical evidence, founder narrative, and fallback remain untouched.

The existing H5 engine, probes, synthetic fixtures, and H5 tests are reused. The engine's two changes are to disable all external capture input and to replace a private historical launcher with a portable boundary notice. The former personal-target exclusion is subsumed by refusing every external target; it is not removed while leaving external capture enabled. Two inherited external-interface tests now assert that stricter public-candidate refusal. All remaining identity, schema, scope, provenance, bounded-I/O, path, hash, interruption, and authority behavior is retained.

The launcher calls the existing default H5 synthetic demo and labels the excluded historical/genuine evidence. Seven export boundary tests and public-safe setup, privacy, security, license-review, and dependency documents are added. No new continuity semantics, transport, architecture, persistence system, or development phase is introduced.

The genuine no-change checkpoint answer, private correction/withdrawal demonstration, and founder narrative are deliberately absent. Fictional examples are not replacements for their authenticity. The full public file inventory and hashes are in `RELEASE-MANIFEST.json`.
