# Privacy boundary

The original runtime remains fictional-only. Proposed docs add founder-approved high-level narrative; no private operational biography or Core state is imported. Personal Bee account observations, personal record identifiers/text, transcripts, private founder lineage and operational biography, private receipts, capture timestamps from personal records, account state, credentials, authentication stores, personal continuity state, and private filesystem paths are excluded. The original private packages and working fallback remain preserved separately.

The release has no Bee transport. External ingestion is disabled. Playback generates synthetic local receipts only. Nothing is uploaded or published. If an operator edits fictional fixtures to contain personal information, that information can appear in local output and receipts; the program is not a general privacy scrubber. Review any changed fixtures and generated output before sharing.

Excluded genuine evidence is a material proof limitation: the candidate cannot establish that actual Bee data produced its result, that a wearable produced an observation, or that a genuine source changed. It demonstrates the existing local continuity mechanism using synthetic data.

Public output includes no private checkpoint receipt or private archive inventory. All shipped integrity hashes bind public code and fictional fixtures only. The private verification directory is outside the staged tree and must not be added to a future public repository.
